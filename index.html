使用设备

统一订阅按 UA 输出 sing-box、Clash/Mihomo 或 v2rayN / v2rayNG / 小火箭节点订阅。未知 UA 默认返回通用节点格式；可添加 ?target=singbox、clash、xray 手动指定。节点订阅不携带 TUN、分流和去广告策略，需在对应客户端中设置。

sing-box 已适配 1.15 新 TUN 栈，不写入弃用的 stack 选项。1.15 当前为预发布版，亦兼容 1.14.3 稳定版。

手机：Android / iOS，使用兼容客户端的 VPN 模式。电脑：Windows / macOS / Linux，TUN 需要管理员/root 权限或客户端服务模式；系统代理模式使用 127.0.0.1:7890。v2rayN / v2rayNG / Shadowrocket 请选择统一订阅；原版 Clash 无法使用现代节点配置。

链接是访问凭证，请勿公开。上游订阅会在客户端更新时重新获取，服务器缓存 5 分钟。

使用客户端的扫码导入功能。二维码与订阅链接具有相同访问权限，请勿公开。
